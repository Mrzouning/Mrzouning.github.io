Welcome to Hexo！这是我的第一篇文章，也是在这个博客里留下的第一枚坐标。以后会在这里记录代码、产品、学习，以及一些生活的碎片。

博客不需要一开始就很完整。先写下第一句话，剩下的内容，我们边走边补。

Quick Start

如果你也想快速开始一个 Hexo 博客，可以按照下面的流程完成初始化。

Create a new post

$ hexo new "My New Post"

更多信息可以阅读 Writing 文档。

Run server

$ hexo server

本地启动后，打开浏览器查看实时预览。

Generate static files

$ hexo generate
$ hexo deploy

这就是这间小屋最初的样子。谢谢你来看看。
